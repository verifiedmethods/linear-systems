# AI tools in unit A2: a statement you can adopt

Students may use AI tools (such as ChatGPT, Claude, Gemini or Copilot) to
explain the methods, to answer questions about Python, and to help find bugs,
provided they **disclose this** in `student/student_info.txt`. The disclosure
appears on their verification report.

Students are expected to write the three sweep functions themselves. If any part
of the code came from an AI tool or from another person, they must say so in the
disclosure and in `CONTRIBUTION.md`; the supervisor decides how this affects the
marks.

The analysis, the interpretation and the written report must be the student's
own work. A student remains responsible for every line of code they submit and
must be able to explain it in a viva, whoever or whatever helped write it.

Any claim in a report that a computation succeeded must be supported by an
actual run (the verification report or the student's own output), never by text
produced by an AI tool.

This statement will be revised to align with national guidance on AI in
universities (for example from the National Universities Commission) when it is
published.
